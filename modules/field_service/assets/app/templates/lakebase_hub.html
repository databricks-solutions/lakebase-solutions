Autoscale under fire

Ramp CPU-bound load in stages and watch Lakebase autoscale compute to match. Per Databricks, Lakebase autoscaling continuously monitors CPU load, memory, and working-set size and adjusts Compute Units within your min–max range (each CU ≈ 2 GB RAM), with no connection interruption. Each scale event is called out below with the reason it fired. CU is read live from the local file cache. Best from a cold start (1 CU) — scale-down takes a few minutes, so let it settle before re-firing.
