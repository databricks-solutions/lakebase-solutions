How This Works: Lakebase Branching

Production Branch

  • Your app’s operational database
  • Autoscaling compute — scales to zero when idle ($0 cost)
  • Built-in connection pooler
  • PostgREST Data API (auto-generated REST)

What-If Branch

  • Instant zero-copy branch of production
  • Copy-on-write — pay only for changed rows
  • Run scenarios in full isolation
  • Discard when done — production untouched

How branching works: Creating a branch is an instant, copy-on-write clone — the new branch shares all data with its parent through storage pointers, so you only pay for rows you actually change (near-zero additional storage). A separate compute endpoint then activates so you can connect — end to end, you're querying a full branch of production in seconds. Changes on the branch never affect the parent.
